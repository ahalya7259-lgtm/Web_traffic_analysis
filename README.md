# Web Traffic Analysis

Analysis of website traffic data to understand visitor behavior, peak hours, sources and engagement trends.

> **Portfolio project** — practical data analytics with Python & Jupyter.

## Overview
This project examines web traffic logs / metrics to answer:
- When do users visit the most?
- Which pages or channels drive the highest traffic?
- How can the site improve user experience based on the data?

## Tools & Libraries
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook
